# Itty 001 — AI layered artwork

- `itty-001-full-render.png`: original AI 3D character render with transparent background.
- `itty-001-exploded-layers.png`: AI exploded view with the components spaced apart.
- `itty-001-layers.ora`: editable OpenRaster stack. Open it in Krita, GIMP, or another OpenRaster-compatible editor.
- `itty-001-layered-preview.png`: transparent composition from the layer stack.
- Individual PNGs are cropped to their content to keep the package lighter; the ORA file preserves their offsets on the shared 1024 × 1536 canvas.

The stack separates the eraser, ferrule, pencil character, wood, and graphite point. The face and both arms are grouped with the pencil body. No legs are present.
