# Itties trait artwork

AI-rendered 3D concept sheets for the seven trait categories. Each sheet shows six options in a 3-column × 2-row grid; read left-to-right across the top row, then left-to-right across the bottom row to match the option order in `../traits.md`.

These are presentation sheets, not individually isolated production NFT files. The images are saved as WebP to keep them lightweight. The site displays them in its interactive Trait layers explorer.

## Female archetype traits

The separate blueprint-specific female traits are in female/. The OpenRaster file contains transparent category layers for hair color, lip color, and apparel, with the named options documented there.
